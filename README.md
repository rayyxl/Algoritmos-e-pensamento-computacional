## 💻 Sobre o repositório

Este repositório reúne os códigos desenvolvidos ao longo da disciplina de **Algoritmos e Pensamento Computacional**.

As atividades são desenvolvidas utilizando a linguagem **C**, com o objetivo de colocar em prática os conceitos de algoritmos, lógica de programação e pensamento computacional apresentados durante as aulas.

## 📚 Conteúdos

Entre os conceitos trabalhados na disciplina estão:

* Algoritmos;
* Lógica de programação;
* Variáveis e tipos de dados;
* Operadores;
* Estruturas condicionais;
* Estruturas de repetição;
* Funções;
* Vetores e matrizes;
* Programação em C.

## 📂 Organização do repositório

O repositório é organizado por **aulas**. Cada aula possui seus respectivos **exercícios**, sendo cada exercício armazenado em sua própria pasta.

A estrutura será ampliada conforme novas aulas e exercícios forem desenvolvidos durante a disciplina.
